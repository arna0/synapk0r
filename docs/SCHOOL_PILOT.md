# School pilot for the SynapKor IT simulation

## Aim

Find out whether students in grades 8–11 can complete the practice run in class and use timestamps and service logs to identify the cause of a different outage.

## One 35-minute lesson

1. **3 min:** Explain that results describe a simulation run. Assign anonymous participant codes and alternate which prompt students see first.
2. **4 min:** Give students prompt A or B as a short pre-test, with no hints.
3. **10 min:** Have students play the guided IT module. Ask them to record any point where they needed help from another person.
4. **5 min:** Give each student the other prompt as a post-test. Score before discussing the answers.
5. **8 min:** Let students try the second incident in the simulator and discuss which log entry drove their choice.
6. **5 min:** Ask the counselor where students needed support and whether they would use the activity again.

## Equivalent pre/post prompts

- **A.** 09:00 backup disk 80%. 09:01 release installed. 09:02 checkout reports missing region setting. 09:03 database check passes. 09:04 checkout returns 503. What most likely caused the outage? Which line supports your answer?
- **B.** 11:00 battery monitor awaiting replacement. 11:01 new settings loaded. 11:02 bookings reports missing timezone setting. 11:03 database check passes. 11:04 bookings returns 503. What most likely caused the outage? Which line supports your answer?

Use one point for identifying the missing setting in the new release and one point for identifying the corresponding log entry. Record scores from 0 to 2. Keep the rubrics identical across both prompts.

## What to record

Participant code, prompt order, language, device type, pre-score, post-score, completion, number of hints shown, help from another person, and the step where a student got stuck. Record totals and the change for students with both scores. The counselor records willingness to run a second session and practical changes needed first. Use the school’s process for collecting student feedback and store only the fields needed for this pilot.
