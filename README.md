# 🌐 SynapKor (JobSim AI) — 3D Платформа симуляции профессий & ИИ-оценки навыков

**SynapKor** — это интерактивная 3D/VR платформа для обучения, профориентации, тренинга моторики и комплексной оценки профессиональных компетенций (Hard / Soft / Management Skills) с использованием телеметрии движений и ИИ-аналитики.

> **Статус проекта: MVP (Минимально жизнеспособный продукт)**  
> Профессия **«Бариста»** выступает в качестве первого демонстрационного модуля (Showcase MVP), на котором отработаны механики физического взаимодействия, квестовая система, трекинг точности и генерация персональных ИИ-отчетов (Fit Score).

---

## 💡 Концепция платформы

Платформа решает задачи быстрого онбординга, грейдирования и практического тестирования специалистов без риска испортить сырье или оборудование.

Каждая профессия в системе раскладывается на три ключевых блока оценки:
1. **Hard Skills (Прикладная моторика и техкарты)** — пошаговое выполнение регламентов на реалистичном 3D-оборудовании с контролем точности, таймингов и физических действий.
2. **Soft Skills (Коммуникация и стрессоустойчивость)** — интерактивные диалоговые симуляции с клиентами, коллегами и решение конфликтных ситуаций.
3. **Management / Economics (Операционный менеджмент)** — работа с кассой, расчет сырья, закупки, управление рисками и предотвращение убытков.

## ☕ Текущий MVP-модуль: Профессия «Бариста»

В качестве первого пилотного сценария реализована полноценная симуляция работы бариста в кофейне:

### 1. Реалистичное 3D рабочее место (Three.js / WebGL)
- **Оборудование**: Двухгруппная эспрессо-машина с манометрами, группами пролива и стимерами для молока.
- **Инструменты**: Профессиональная он-деманд кофемолка с зерновым бункером, холдер 58 мм, стальной темпер (20 кг) с ковриком, питчер для молока.
- **Ингредиенты и сборка**: Кофейное зерно, овсяное молоко (Oat Milk), лед, стакан с динамической физикой наполнения и слоев напитка.
- **Эффекты**: Система частиц пара и экстракции эспрессо под давлением 9 бар.

### 2. Сквозной цикл тестирования (3 квеста)
- 🛠 **Квест 1: Hard Skills (Iced Oat Latte)** — 6-шаговый пайплайн моторики: `Взять холдер` ➔ `Помол 18г` ➔ `Темперовка 20кг` ➔ `Экстракция эспрессо` ➔ `Взбивание молока` ➔ `Сборка напитка`.
- 💬 **Квест 2: Soft Skills (Конфликт с гостем)** — диалоговый сценарий с недовольным посетителем, проверка клиентоориентированности и эмоционального интеллекта.
- 📊 **Квест 3: Management (Касса и закупки)** — расчет недельного расхода кофе, оптимизация бюджета и предотвращение дефицита зерна.

### 3. ИИ-телеметрия и Fit Score
- Замер точности выполнения операций (Step Accuracy).
- Детекция тремора и плавности перемещения курсора/камеры (Hand Shakiness Detection).
- Итоговый расчет соответствия профессии (**Fit Score**) с персональными рекомендациями по зонам роста.

## 🔮 Дорожная карта профессий (Roadmap)

Модульная архитектура платформы позволяет масштабировать симулятор на другие специальности:
- 🍳 **Повар / Пиццайоло / Су-шеф** (кухонные процессы, санитарные нормы, тайм-менеджмент заказов).
- 🔧 **Автомеханик / Автослесарь** (диагностика, регламентное ТО, замена узлов).
- 💊 **Фармацевт / Провизор** (подбор рецептурных препаратов, консультации, работа с базой).
- ⚙️ **Оператор станков / ЧПУ** (промышленная безопасность, настройка оборудования).

## 🎮 Управление в симуляторе

- **Перемещение**: Клавиши `W`, `A`, `S`, `D` или экранный виртуальный джойстик (D-Pad).
- **Обзор камеры (FPS View)**: Зажатие левой кнопки мыши + перемещение / свайп по экрану (Touch).
- **Взаимодействие с предметами**: Наведение прицела (Crosshair) и клавиша `E`, либо `Space` (Пробел), либо клик/тап по объекту.
- **Подсказки**: Внизу экрана отображается текущий шаг пайплайна и контекстные инструкции.

## 🚀 Как запустить проект

### Вариант 1. Запуск Web-версии симулятора (Быстрый старт)

Симулятор доступен через встроенный веб-сервер:

#### С помощью Python:
```bash
python -m http.server 8080 --directory web_preview
```
После запуска откройте в браузере: **`http://localhost:8080`**

#### С помощью Node.js / npx:
```bash
npx serve web_preview -l 8080
```

---

### Вариант 2. Запуск мобильного приложения Flutter

Для запуска на Android, iOS, Windows или Web через Flutter SDK:

```bash
# Получение зависимостей
flutter pub get

# Проверка доступных устройств
flutter devices

# Запуск на подключенном устройстве / эмуляторе
flutter run
```

## 🛠 Технологический стек

- **3D Графика**: Three.js (WebGL, ACES Filmic Tonemapping, PCF Soft Shadows, процедурный звук WebAudio API).
- **Frontend / Mobile**: Flutter 3.x, Dart, Provider, Google Fonts, WebView Flutter.
- **Дизайн**: Pro SaaS Theme (Tailored HSL/Hex, Smooth Micro-animations, Glassmorphism).
- **Аналитика**: Встроенный модуль телеметрии моторики и расчет персонального Fit Score.
