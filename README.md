# ☕ SynapKor — Professional Barista VR Simulator

Интерактивный 3D VR-тренажер и симулятор для обучения, тестирования моторики и оценки профессиональных навыков бариста с телеметрией и ИИ-анализом.

---

## 🎯 Основные возможности

1. **Реалистичное рабочее место бариста в 3D (WebGL / Three.js)**:
   - Двухгруппная эспрессо-кофемашина компрессионного типа с группами пролива, манометрами и паровыми кранами (стимерами).
   - Профессиональная он-деманд кофемолка с прозрачным бункером для кофейных зерен.
   - Портафильтр (холдер) 58 мм с точной фиксацией в кофемолке и группе.
   - Тяжелый стальной темпер и демпфирующий силиконовый коврик для темперовки (20 кг).
   - Питчер для молока и коробка растительного овсяного молока (Oat Milk).
   - Прозрачный стакан для напитка с динамическим уровнем жидкости (эспрессо + вспененное молоко) и кубиками льда.
   - Система частиц для пара и экстракции эспрессо (9 бар).

2. **3 игровых квеста полного цикла оценки**:
   - **Квест 1: Hard Skills (Iced Oat Latte)** — 6-шаговый пайплайн моторики (взять холдер → помол 18г → темперовка 20кг → экстракция эспрессо → взбивание овсяного молока → сборка Iced Latte).
   - **Квест 2: Soft Skills (Конфликт с гостем)** — проверка эмоционального интеллекта и стрессоустойчивости при взаимодействии с недовольным посетителем.
   - **Квест 3: Management (Касса и закупки)** — расчет недельного расхода кофейного зерна, управление бюджетом и предотвращение кассовых разрывов/дефицита.

3. **ИИ-аналитика и телеметрия (Fit Score)**:
   - Оценка точности движений (Step Accuracy) и тремора рук (Hand Shakiness Detection).
   - Оценка времени приготовления напитка и соблюдения технологической карты.
   - Формирование детального отчета с персональными рекомендациями.

## 🎮 Управление в симуляторе

- **Перемещение**: Клавиши `W`, `A`, `S`, `D` или экранный виртуальный джойстик (D-Pad).
- **Обзор камеры (FPS View)**: Зажатие левой кнопки мыши + перемещение / свайп по экрану (Touch).
- **Взаимодействие с предметами**: Наведение прицела (Crosshair) и клавиша `E`, либо `Space` (Пробел), либо клик/тап по подсвеченному предмету.
- **Подсказки**: Внизу экрана отображается текущий шаг пайплайна и контекстные инструкции.

## 🚀 Как запустить проект

### Вариант 1. Запуск Web-версии симулятора (Быстрый старт)

Симулятор доступен через встроенный веб-сервер:

#### С помощью Python:
```bash
python -m http.server 8080 --directory web_preview
```
После запуска откройте в браузере: **`http://localhost:8080`**

#### С помощью Node.js / npx:
```bash
npx serve web_preview -l 8080
```

---

### Вариант 2. Запуск мобильного приложения Flutter

Для запуска на Android, iOS, Windows или Web через Flutter SDK:

```bash
# Получение зависимостей
flutter pub get

# Проверка доступных устройств
flutter devices

# Запуск на подключенном устройстве / эмуляторе
flutter run
```

## 🛠 Технологический стек

- **3D Графика**: Three.js (WebGL, ACES Filmic Tonemapping, PCF Soft Shadows, процедурный звук WebAudio API).
- **Frontend / Mobile**: Flutter 3.x, Dart, Provider, Google Fonts, WebView Flutter.
- **Дизайн**: Pro SaaS Dark Theme (Tailored HSL/Hex, Smooth Micro-animations, Glassmorphism).
